## Purpose

CKES adopts EDF baseline governance. Full governance policy set is deferred to Governed tier maturity.

## Baseline Requirements

- Document metadata on governed documents (Status, Owner, Applies To, Last Reviewed)
- Git-native review for documentation changes
- Classification discipline on experimental findings
