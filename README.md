# Canonical Knowledge Engineering System (CKES)

CKES is an independent architectural research, experimentation, and prototyping project that investigates how CRA-adopting systems can acquire, canonicalize, and maintain canonical knowledge at practical scale and cost.

CKES is an **Architecture Specification Repository (ASR)** governed by the [Engineering Documentation Framework](ENGINEERING_DOCUMENTATION_FRAMEWORK.md). It is not the Canonical Representation Architecture (CRA) itself.

## Status

- **EDF bootstrap:** Complete (ASR, `profile: core`)
- **POC:** Experimental reference implementation in [`poc/`](poc/README.md) — non-normative
